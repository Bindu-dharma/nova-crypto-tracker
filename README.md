Cryptocurrency Price Tracker

Project Description

The Cryptocurrency Price Tracker is a Python-based mini project that fetches cryptocurrency prices in real time using the CoinGecko API.

Features

* Displays Bitcoin prices.
* Displays Ethereum prices.
* Displays Dogecoin prices.
* Displays Solana prices.
* Shows cryptocurrency prices in USD.

Technologies Used

* Python
* Requests Library
* CoinGecko API

How to Run

1. Install Python.
2. Install the required library using pip install -r requirements.txt.
3. Run the program using python crypto_tracker.py.

Output

Displays the latest available prices of four cryptocurrencies in USD.

Conclusion

This project demonstrates API integration and real-time data retrieval using Python.
